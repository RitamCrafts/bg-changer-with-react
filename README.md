# 🎨 Background Color Changer

A simple React app to change the background color using buttons. Built with **React**, **Tailwind CSS**, and **Vite**.

---

## 🚀 Features

* Change background color with a single click
* Clean UI using Tailwind CSS

---

## 🛠️ Tech Stack

* React
* Vite
* Tailwind CSS

---

## 📦 Installation

```bash
# Clone the repo
git clone https://github.com/your-username/bg-changer.git

# Go to project folder
cd bg-changer

# Install dependencies
npm install

# Start development server
npm run dev
```
